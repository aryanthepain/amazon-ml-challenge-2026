<objective>
Implement the LightGBM classifier training engine (`src/model.py`), exact competition Macro $F_{0.5}$ metric and threshold calibration engine (`src/tuning.py`), single-match inference resolver (`src/matcher.py`), and CLI execution pipelines for Phase 3.

Purpose:
Downstream entity resolution requires a high-precision GBDT model and an optimal decision threshold $\theta^* \approx 0.70$ that balances precision $2\times$ over recall and protects singleton entity accuracy (>95% singletons) to maximize the official Macro $F_{0.5}$ leaderboard score.

Output:
- `src/model.py`: LightGBM training wrapper with early stopping on validation ROC-AUC, feature importance exporter, and model persistence.
- `src/tuning.py`: Exact competition Macro $F_{0.5}$ metric computation and grid-search threshold calibration over $\theta \in [0.40, 0.90]$.
- `src/matcher.py`: Inference matcher selecting $\arg\max P(\text{match})$ for candidates exceeding $\theta^*$, or assigning `None` (singleton).
- `scripts/train_gbdt.py`: CLI training script producing `models/lgbm_matcher.txt`.
- `scripts/tune_threshold.py`: CLI threshold tuner outputting calibrated $\theta^*$ and validation metric report.
- `scripts/predict_matches.py`: CLI prediction script generating verified candidate matches for test submissions.
- `tests/test_phase3_model.py`: Pytest suite verifying model convergence, threshold search, single-match assignment, and singleton protection.
- `scripts/verify.ps1`: Updated verification harness running all Phase 3 tests.
</objective>

  <action>
    Create `src/tuning.py` to evaluate the exact competition metric and find $\theta^*$:
    1. Implement `compute_macro_f05(precision: float, recall: float) -> float`:
       - Computes $F_{0.5} = (1 + 0.25) \cdot \frac{P \cdot R}{0.25 P + R}$ where precision is weighted $2\times$ over recall. Handles edge case $P + R == 0$ returning 0.0.
    2. Implement `evaluate_validation_predictions(val_s1_ids: set, ground_truth_dict: Dict[str, str], candidate_preds_dict: Dict[str, List[Tuple[str, float]]], theta: float) -> Dict[str, float]`:
       - For every S1 entity in `val_s1_ids`:
         - Retrieve true target match from `ground_truth_dict` (None if singleton).
         - Filter candidate predictions where $P(\text{match}) \ge \theta$.
         - If non-empty: assign candidate with $\arg\max P(\text{match})$. If empty: assign `None` (singleton).
         - Compare prediction to ground truth:
           - Correct match: $TP += 1$
           - Predicted candidate != true target: $FP += 1$, $FN += 1$
           - Predicted candidate on a true singleton: $FP += 1$
           - Predicted singleton on a true non-singleton: $FN += 1$
           - Predicted singleton on a true singleton: True Negative (correctly rewarded, zero FP/FN)
       - Compute precision $P = TP / (TP + FP)$, recall $R = TP / (TP + FN)$, $F_{0.5}$, and singleton accuracy $TN / N_{singletons}$ (D-11).
    3. Implement `grid_search_threshold(val_s1_ids: set, ground_truth_dict: Dict[str, str], candidate_preds_dict: Dict[str, List[Tuple[str, float]]], theta_min: float = 0.40, theta_max: float = 0.90, step: float = 0.02) -> Tuple[float, float, pd.DataFrame]`:
       - Evaluates candidate thresholds across $[0.40, 0.90]$ with step $0.02$ (D-09).
       - Selects $\theta^*$ maximizing Macro $F_{0.5}$ while ensuring singleton accuracy $\ge 0.95$ (D-11).
       - Returns `(best_theta, best_f05, tuning_curve_df)`.
  </action>
  <acceptance_criteria>
    - `src/tuning.py` exists and implements `compute_macro_f05` and `grid_search_threshold`.
    - Macro $F_{0.5}$ accurately computes $\beta=0.5$ weighted score ($P=1.0, R=0.5 \implies F_{0.5} \approx 0.833$).
    - `grid_search_threshold` evaluates the full range $[0.40, 0.90]$ and outputs a dataframe with precision, recall, $F_{0.5}$, and singleton accuracy per threshold.
    - True singletons are cleanly preserved when threshold is sufficiently high.
