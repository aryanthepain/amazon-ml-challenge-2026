  <action>
    Create `src/preprocessing.py` implementing foundational text sanitization:
    1. `strip_accents(text: str) -> str`: Normalizes with `unicodedata.normalize('NFKD', text)` and filters out combining diacritic marks (`c for c in nfkd if not unicodedata.combining(c)`). Converts accented Latin characters (`é` -> `e`, `ç` -> `c`, `ü` -> `u`, `ö` -> `o`) while preserving Indic and non-combining characters intact (D-10).
    2. Null/empty text sanitizer: Helper checking `text is None or not isinstance(text, str) or text.strip() in ("", "nan", "null", "none")` returning empty string `""`.
    3. Punctuation and whitespace cleaners: `PUNCT_REGEX = re.compile(r'[^\w\s]', flags=re.UNICODE)` and `MULTI_SPACE_REGEX = re.compile(r'\s+')`.
    4. Replace non-breaking spaces `\u00a0`, tabs, carriage returns, and newlines with standard space.
  </action>

    - `strip_accents("Café de la Société")` returns `"Cafe de la Societe"`.
    - `strip_accents(None)` and `strip_accents("nan")` return `""`.
    - Indic transliterated words (e.g. Hindi/Tamil romanized business names) remain intact without character loss.

  <action>
    In `src/preprocessing.py`, implement full business name and address normalizers:
    1. Compile `LEGAL_SUFFIX_REGEX` covering 35+ international extensions (D-09):
       - US: `private limited`, `pvt ltd`, `pvt`, `limited liability company`, `llc`, `limited liability partnership`, `llp`, `incorporated`, `incorporation`, `inc`, `corporation`, `corp`, `limited`, `ltd`, `company`, `co`, `professional corporation`, `pc`
       - India: `enterprises`, `trading company`, `trading co`, `industries`, `solutions`, `services`
       - France: `societe anonyme`, `sa`, `societe par actions simplifiee`, `sas`, `societe a responsabilite limitee`, `sarl`, `entreprise unipersonnelle a responsabilite limitee`, `eurl`, `societe en nom collectif`, `snc`
       - Europe: `gmbh`, `ag`, `bv`, `nv`, `spa`
       Use word boundaries `\b` and order patterns from longest to shortest to prevent premature sub-token matching.
    2. `normalize_business_name(name: Optional[str]) -> str`:
       - Strips accents, converts to lowercase.
       - Replaces `&` with ` and `, `@` with ` at `.
       - Applies `LEGAL_SUFFIX_REGEX.sub(' ', s)`.
       - Applies `PUNCT_REGEX.sub(' ', s)`.
       - Collapses whitespace and trims.
    3. Compile `STREET_REGEX_PATTERNS` and `STATE_REGEX_PATTERNS` expanding road/unit/state abbreviations (D-11):
       - `st` -> `street`, `rd` -> `road`, `ave` -> `avenue`, `blvd` -> `boulevard`, `dr` -> `drive`, `hwy` -> `highway`, `ln` -> `lane`, `ct` -> `court`, `pkwy` -> `parkway`, `ter` -> `terrace`, `ste` -> `suite`, `apt` -> `apartment`, `fl` -> `floor`, `no` -> `number`.
       - US states (`ny` -> `new york`, `ca` -> `california`, `tx` -> `texas`, `fl` -> `florida`, `il` -> `illinois`, `pa` -> `pennsylvania`, etc.).
       - Indian states (`up` -> `uttar pradesh`, `mp` -> `madhya pradesh`, `mh` -> `maharashtra`, `ka` -> `karnataka`, `dl` -> `delhi`, `tn` -> `tamil nadu`, etc.).
    4. `normalize_business_address(address: Optional[str]) -> str`:
       - Expands street, unit, and state abbreviations.
       - Strips punctuation while preserving digits and street numbers.
       - Collapses whitespace and trims.
    5. `create_search_text(name: Optional[str], address: Optional[str], name_weight: int = 2) -> str`:
       - Normalizes name and address.
       - Concatenates with name weighted 2x: `((clean_name + " ") * name_weight + clean_addr).strip()` (D-12).
  </action>
  <acceptance_criteria>
