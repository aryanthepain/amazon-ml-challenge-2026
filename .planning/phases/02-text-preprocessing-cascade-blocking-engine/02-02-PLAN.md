<objective>
Build the country-partitioned cascade blocking engine, candidate pair generator, streaming TSV exporter, Parquet cache, and recall ceiling audit harness for Phase 2.

Purpose:
Downstream model feature extraction (Phase 3) requires high-recall candidate sets ($\ge 95\%$) while shrinking the 17.6-trillion pair space by $>99.9\%$ and outputting official `output/candidate_pairs.tsv`.

Output:
- `src/blocking.py`: 4-stage inverted index, batched TF-IDF sparse blocker, country partitioner, and candidate generator.
- `scripts/run_blocking.py`: CLI runner to execute blocking on dev slices or full splits.
- `scripts/audit_blocking_recall.py`: Recall ceiling auditing CLI generating `output/blocking_recall_audit.json`.
- `tests/test_phase2_blocking.py`: Pytest suite testing country isolation, cascade stages, singleton spec compliance, and official validator exit 0.
- `scripts/verify.ps1`: Deterministic verification gate for Phase 2.
</objective>

  <files>src/blocking.py</files>
  <action>
    Create `src/blocking.py` with:
    1. `InvertedIndexCascade`: Builds dictionaries mapping exact keys to candidate lists for a target DataFrame:
       - `by_both`: `clean_name + "::" + clean_addr` (only if `len(clean_addr) >= 8`)
       - `by_name`: `clean_name` (only if `len(clean_name) >= 3`)
       - `by_addr`: `clean_addr` (only if `len(clean_addr) >= 10`, filtering out generic road stopwords)
       - `by_pref`: First 2 significant tokens of `clean_name` (`t0 + "_" + t1`, length $\ge 4$)
       Provides `query_exact(s1_name, s1_addr)` returning `[(cand_id, stage_name), ...]`.
    2. `TfidfSparseBlocker`:
       - Fits `TfidfVectorizer(analyzer='char_wb', ngram_range=(3, 4), max_features=150000, sublinear_tf=True, dtype=np.float32)`.
       - Fits and transforms target corpus ($S_2 + S_3$ search text).
       - Transposes target matrix once to CSC format: `target_matrix.T.tocsc()`.
       - Queries $S_1$ search text in batches (adaptive batch size: 50 for $>1\text{M}$ targets, 200 for $>200\text{K}$, 1000 otherwise).
       - Performs batched dot product `s1_batch.dot(target_matrix_t)`.
       - Slices CSR arrays directly, filters by `min_similarity >= 0.18`, and extracts top fuzzy candidates.
    3. `BlockingEngine`:
       - Dynamic country partitioning: groups by `df['country'].dropna().unique()` (D-03).
       - Merges S2 and S3 into unified target pool per country (D-02).
       - Combines exact inverted index matches with TF-IDF fuzzy candidates:
         - Exact matches placed first, deduplicated by candidate ID (D-07).
         - Remaining slots up to $K=25$ filled by TF-IDF candidates sorted descending by cosine score (D-05, D-06).
         - If zero candidates pass, maps to empty list (D-08).
    4. Exporters:
       - `export_candidate_pairs_tsv(candidates_dict, output_path, chunk_size=50000)`: Writes `source1_entity_id\tcandidate_ids` where candidate IDs are comma-separated and sorted. Emits `S1-ID\t` for singletons (D-08, D-13).
       - `export_candidate_parquet_cache(candidates_records, cache_dir, country)`: Writes tabular DataFrame with columns `['s1_id', 'candidate_id', 'blocking_stage', 'rank', 'cosine_sim']` to `data/cache/candidates/country={country}/candidates.parquet` (D-14).
  </action>

    1. Create `scripts/run_blocking.py` CLI:
       - CLI flags: `--split {train,val,test,dev}`, `--sample-size N`, `--output-tsv`, `--cache-parquet`, `--data-dir`.
       - Loads $S_1$, $S_2$, $S_3$ datasets using `DataLoader` from `src/data_loader.py`.
       - If `--split val`, filters $S_1$ by `data/splits/val_s1_ids.tsv`.

       - Executes `BlockingEngine.block_datasets`.
       - Streams results to `output/candidate_pairs.tsv` in 50,000-row chunks.
       - Optionally saves partitioned Parquet cache to `data/cache/candidates/`.
    2. Create `scripts/audit_blocking_recall.py` CLI (D-15, BLOCK-04):
       - Reads candidate pairs from `output/candidate_pairs.tsv` (or takes in-memory candidates).
       - Loads `data/splits/val_ground_truth.tsv` and `data/splits/val_s1_ids.tsv`.
       - Evaluates empirical recall ceiling:
         - Positive pairs in ground truth captured in candidate sets.
         - Recall ceiling percentage: $(\text{captured positive pairs} / \text{total positive pairs}) \times 100\%$.
         - Country breakdown: recall for US vs India.
         - Singleton accuracy: percentage of true singletons assigned empty candidate string.
         - Comparison space reduction factor: $1 - (\text{total candidate pairs} / (N_{S1} \times (N_{S2} + N_{S3})))$.
       - Emits structured report to `output/blocking_recall_audit.json`.
       - Fails with exit code 1 if recall ceiling $< 95\%$.
  </action>
