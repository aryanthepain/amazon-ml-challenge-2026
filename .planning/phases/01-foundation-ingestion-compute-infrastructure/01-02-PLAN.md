<objective>
Build the remote Kaggle dual-T4 GPU automation pipeline, pre-flight authentication doctor, dataset packager, and kernel dispatcher for Phase 1.

Purpose:
Processing 1.73M test entities in candidate blocking and inference exceeds local laptop hardware limits (RTX 3050, 4GB VRAM). Kaggle provides dual-T4 GPUs (32GB VRAM, 30GB RAM, 4 vCPUs). Automating kernel dispatch, status polling, and artifact retrieval via the Kaggle CLI enables seamless remote execution.

Output:
- `scripts/verify_kaggle_env.py`: Automated pre-flight Kaggle API and credentials doctor.
- `scripts/kaggle_dataset.py`: Kaggle dataset packager and synchronization helper.
- `scripts/kaggle_runner.py`: Kernel packager, CLI dispatcher, status poller, and artifact synchronizer.
- `kaggle/kernel-metadata.json` & `kaggle/kaggle_entrypoint.py`: Dual-T4 GPU smoke kernel entrypoint.
- `tests/test_kaggle_env.py`: Unit test verifying Kaggle CLI packager logic and configuration files.
</objective>
